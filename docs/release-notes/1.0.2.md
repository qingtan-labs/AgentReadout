# Gauge for Codex 1.0.2

This hotfix makes the new desktop widgets receive live quota data in the public ad-hoc-signed build.

## Fixed

- Removed the App Group dependency that requires an Apple Team ID and therefore could not be written by the public ad-hoc-signed app.
- The widget now reads Gauge for Codex's existing local preferences directly, while the host app triggers an immediate WidgetKit timeline reload after each quota refresh.
- Removed repeated App Group preference-write errors from the menu-bar process.

## Included from 1.0.1

- Native small and medium desktop widgets on macOS 14 or later.
- Manual update checks and automatic checks once a day, with an off switch.
- Verified automatic update download, replacement, rollback, and relaunch.
- English, Simplified Chinese, Japanese, and Spanish localizations.

Public builds are ad-hoc signed and are not Apple-notarized. After dragging the app to Applications, Control-click it and choose **Open** on first launch. Do not disable Gatekeeper.

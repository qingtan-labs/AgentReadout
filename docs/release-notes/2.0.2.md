# AgentReadout 2.0.2

Daily Token widgets now use their own refresh schedule and advance the seven-day chart at midnight. Quota updates no longer consume the Daily Token refresh budget. This release also recognizes the Codex CLI bundled inside newer ChatGPT installations.

The source installer migrates the legacy app name to `AgentReadout.app` and restarts the current user's widget services after that one-time path change, preventing macOS from trying to launch a removed extension. Existing settings, widget identifiers, and usage data are preserved.

The app, native widget, and optional launcher use build 38. AgentReadout is an independent third-party utility, not affiliated with or endorsed by OpenAI or Anthropic.

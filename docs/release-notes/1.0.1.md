# Gauge for Codex 1.0.1

This release adds a desktop quota widget and in-app update checks.

## Desktop widget

- Choose **Desktop Widget → Show on Desktop** from the menu-bar menu.
- The widget is built into the app; it does not appear in macOS's Add Widgets gallery.
- Small layout shows the most constrained quota window, progress, reset countdown, and exact local reset time.
- Medium layout shows both the 5-hour and 7-day windows, each with its own reset time, when both are available.
- The compact title mark matches the Windows edition; small and medium sizes align with macOS widget proportions.
- Drag the widget anywhere; visibility, size, and position persist across launches.
- Finder/desktop focus uses a light system background. Other foreground apps switch it to a subdued material treatment.
- Works across Spaces and recovers to the main display if a saved monitor is disconnected.
- Supports macOS 12 or later without an Apple Developer certificate or extension registration.

## Updates

- Manual update checks are available from the menu.
- Automatic checks run once a day by default and can be disabled.
- Automatic installation verifies SHA-256, bundle identity, version, and code-signing integrity before replacement and relaunch.

## Installation note

This consolidated package is version 1.0.1 (build 5). If you installed any earlier 1.0.1 build or the withdrawn 1.0.2/1.0.3 builds, download and install this package again. The app cannot automatically move from those builds to the consolidated 1.0.1 release.

Public builds are ad-hoc signed and are not Apple-notarized. After dragging the app to Applications, Control-click it and choose **Open** on first launch. Do not disable Gatekeeper.

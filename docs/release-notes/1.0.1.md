# Gauge for Codex 1.0.1

This update adds native desktop widgets and a safer in-app update flow.

## New

- Small widget: the most constrained remaining quota, progress, window length, and reset countdown.
- Medium widget: both the 5-hour and 7-day windows when available, plus the next reset.
- Adaptive macOS styling: full-color light background when desktop widgets are active and a subdued material treatment when the system makes desktop widgets less prominent.
- Manual **Check for Updates** and automatic checks once a day, with a menu switch to turn them off.
- Automatic download, verification, replacement, and relaunch for writable installations.

## Update safety

Automatic installation requires the Universal ZIP and `SHA256SUMS` from the same GitHub release. Gauge for Codex verifies SHA-256, bundle identifier, version, and code-signing integrity before replacing the app. The helper stages the new app beside the current copy and restores the previous copy if replacement or relaunch fails.

## Compatibility

- Menu-bar app: macOS 12 or later.
- Desktop widgets: macOS 14 or later.
- Universal 2: Apple silicon and Intel.

Public builds are ad-hoc signed and are not Apple-notarized. After dragging the app to Applications, Control-click it and choose **Open** on first launch. Do not disable Gatekeeper.

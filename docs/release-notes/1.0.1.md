# Gauge for Codex 1.0.1

This release adds a native macOS desktop quota widget and in-app update checks.

## Desktop widget

- On macOS 14 or later, launch Gauge once, then right-click the desktop, choose **Edit Widgets**, search for **Gauge for Codex**, and add the small or medium native widget.
- The native WidgetKit widget uses the system's desktop background and wallpaper-aware tint. Keep Gauge running to update the quota; the last successful snapshot remains visible if the app is temporarily unavailable.
- On macOS 12–13, choose **Desktop Widget → Show on Desktop** for the draggable floating widget. On newer systems this is available under **Floating Widget (Legacy)**; hide it after adding the native widget if you do not want both.
- Small layout shows the most constrained quota window, progress, reset countdown, and exact local reset time.
- Medium layout shows both the 5-hour and 7-day windows, each with its own reset time, when both are available.
- The compact title mark matches the Windows edition; small and medium sizes align with macOS widget proportions.
- The legacy floating widget uses a neutral translucent background; unlike the native widget, its wallpaper tint cannot perfectly match macOS widgets.
- Respects the macOS Reduce Transparency accessibility setting with an opaque system background.
- The legacy floating widget can be dragged; its visibility, size, and position persist across launches.
- For the floating fallback, Finder/desktop focus uses the system window background; other foreground apps use a translucent material treatment.
- The floating fallback works across Spaces and recovers to the main display if a saved monitor is disconnected.
- The menu-bar app and floating fallback support macOS 12 or later. Native WidgetKit requires macOS 14 or later.

## Updates

- Manual update checks are available from the menu.
- Automatic checks run once a day by default and can be disabled.
- Automatic installation verifies SHA-256, bundle identity, version, and code-signing integrity before replacement and relaunch.

## Installation note

This consolidated package is version 1.0.1 (build 8). If you installed any earlier 1.0.1 build or the withdrawn 1.0.2/1.0.3 builds, download and install this package again. The app cannot automatically move from those builds to the consolidated 1.0.1 release.

Public builds are ad-hoc signed and are not Apple-notarized. After dragging the app to Applications, Control-click it and choose **Open** on first launch. Do not disable Gatekeeper.

# AgentReadout 2.0.0

Gauge for Codex is now **AgentReadout**: one native macOS view for Codex and Claude quota, daily Token activity, and desktop widgets.

## Highlights

- Redesigned menu bar, settings, quota cards, and small/medium/large quota widgets; optional ring style alongside the default bars.
- Codex and Claude plan labels, clear disconnected/stale states, low-quota alerts, and manual fallback for either service.
- Daily Token activity from Codex's existing daily aggregates, with its five cumulative metrics and small/medium/large Token widgets. Claude daily activity is shown only when an existing client statistics cache is available.
- Optional 24-hour quota trends, system-following appearance and language with overrides, and a login-startup switch.
- New bilingual AgentReadout website with a lighter design, draggable signal detail, responsive previews of small/medium/large and Daily Token widgets, and reduced-motion support.
- The application, launcher, website logo, and favicon use the approved 01 deep-blue refined icon. GitHub project and website paths are now named AgentReadout.
- Menu quota cards again show the time remaining until reset alongside the date. Codex and Claude use the same display rule; an unknown or expired reset time is never guessed.

## Upgrade notes

The bundle identifier, widget identifier, URL scheme, and preferences domain stay the same, so existing settings and widgets can migrate. Existing automatic updates keep the application's current filesystem location. New downloads contain `AgentReadout.app`; the source installer still uses the legacy `~/Applications/Gauge for Codex.app` path. If a much older build cannot auto-update, install this release manually.

The release is ad-hoc signed and **not Apple notarized**. Verify the SHA-256 checksums from this release before installation. macOS 12+ is supported; native WidgetKit desktop widgets require macOS 14+.

AgentReadout is an independent third-party utility, not affiliated with or endorsed by OpenAI or Anthropic.

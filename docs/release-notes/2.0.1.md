# AgentReadout 2.0.1

This update restores the relative reset countdown in the menu for both Codex and Claude. Progress-bar cards show the time remaining alongside the reset date; ring cards prioritize the countdown within their smaller layout. Unknown or elapsed reset times are not guessed, and the full timestamp remains available on hover.

The app, widget, and optional launcher use build 36. Existing settings and widget identifiers remain unchanged. Claude can show a countdown only when its data source supplies a valid future reset time.

AgentReadout is an independent third-party utility, not affiliated with or endorsed by OpenAI or Anthropic.

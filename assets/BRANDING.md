# AgentReadout icon source

The approved icon is the **01 deep-blue refined** terminal mark: a white open ring and chevron with one ice-blue cursor. `app-icon.svg` is the vector master, and `app-icon.png` is its reviewed 1024 px raster export. The macOS app and optional launcher both package that exact PNG; website assets are size variants of the same design.

`brand-mark.svg` is the matching monochrome mark for light/dark surfaces. The menu-bar quota indicator remains a functional C/A percentage display, not the square app tile. Avoid reintroducing the earlier gradient progress-ring icon from an old generator or using unselected explorations under `assets/brand/`.

# AgentReadout

AgentReadout（原 Gauge for Codex）是一款独立的原生 macOS 菜单栏额度工具，不绑定 Codex 窗口。为兼容旧版升级，部分内部标识与源码安装路径暂时保留旧名称。

## 体验设计

- 菜单栏默认显示大号本地化百分比和一条细进度条。
- 菜单列出所有可用额度周期，顶部始终显示剩余最少、最需要关注的一档。
- 菜单与中、大号组件在服务名称旁显示明确可识别的会员等级（如 Plus、Pro 5× / 20×、Claude Pro、Max 5× / 20×）；不增加菜单栏宽度，小号仍以额度为主。Codex 使用额度接口的 `planType`，将 `prolite` / `pro` 按官方客户端文案显示为 Pro 5× / 20×；未核实倍数的 Pro 变体只显示 Pro。Claude 使用登录元数据，桌面缓存须与本地账户资料的组织一致才显示套餐，过旧的账户资料不使用。未知套餐不猜测，不会为查套餐新增网络请求。
- 菜单顶部通过 Codex / Claude 双选按钮一键选择菜单栏显示的 C / A（也支持 ⌘1 / ⌘2），选中项带勾，普通点击切换不会收起菜单；未启用 Claude 时仍先征求连接确认。下方两张紧凑服务卡始终同时展示实际周期、套餐、重置时刻和数据来源，未连接服务给出指引。选择不会隐藏另一张卡片；设为「跟随菜单栏」的组件仍跟随选择。
- 右上角回转箭头刷新全部已启用服务，保留 ⌘R；刷新期间显示忙碌状态并防止重复点击。齿轮（⌘,）打开独立设置窗口，分为「通用」「外观与语言」「服务」「更新与关于」。外观可跟随系统或单独选择浅色／深色；语言可跟随系统或单独选择简体中文／英语。菜单与窗口立即切换，原生组件会请求系统刷新。手动额度收在服务页的「高级」，自动更新仍每天最多检查一次。
- 「趋势与用量」把每日 Token 放在首位。为支持原生桌面组件，Codex 官方每日数据在启动、约每 30 分钟及手动刷新时读取；Claude Code 现成统计缓存仅在统计窗口打开时读取。不扫描会话日志、不另存每日历史。24 小时额度趋势单独放在另一页，新用户默认关闭记录。
- 本地额度趋势保留 24 小时，五分钟分桶，可关闭或清空；重置、长时间离线不连成虚假的连续走势。低额度通知默认关闭，开启并允许系统通知后，在剩余 20% / 10% / 耗尽时分档提醒，旧数据不触发，同一周期不重复。
- 每日 Token 支持今天、3 / 7 / 30 天，悬停查看精确每日数值，明确标注来源截止日期；缺失数据不冒充 0。顶部显示 Codex 官方累计 Token、单日峰值、最长单次运行、当前连续天数和最长连续天数，不随图表日期筛选改变。Claude 缓存仅代表本机记录，可能含此前账号。不展示价格、不推算未提供的缓存命中率。
- 「设置 → 通用」可控制登录自启，新安装默认关，升级保留选择。「服务 → 高级」支持 Codex 和 Claude 手动填写 5 小时／7 天剩余额度，重置日期与时、分、秒可直接选择，未知时可单独标记。只更新所选周期并标注手动；下次同步成功恢复官方数据。手动填写 Claude 不会开启登录凭据访问。
- 组件操作归入「桌面组件」，显示方式、通知、记录设置、更新和关于归入「设置」。悬停重置说明可查看完整日期和倒计时，或时间缺失原因；重置时间未提供时仍显示真实百分比，不推算日期。
- 按系统语言、地区和时区显示倒计时及准确重置日期。
- 启动时、每 60 秒、睡眠唤醒后、额度重置后，以及过期时打开菜单都会自动同步。
- 短暂同步失败时保留上次成功值，超过 5 分钟会明确标记“数据可能已过期”。
- 菜单栏拥挤时可切换“仅百分比”紧凑模式。
- macOS 14 及以上提供小号、中号、大号原生 WidgetKit 组件，由系统管理底色与壁纸着色；macOS 12–13 保留可拖动的悬浮组件。
- 新增独立的小、中、大号「每日 Token」桌面组件：点击任意尺寸会直接打开「趋势与用量」的每日 Token 页。小号显示今日用量与近七天迷你图，中号增加累计量和单日峰值，大号为柱状图保留更多高度，下方以无底色的两行文字展示全部五项官方累计指标及更新状态。图表标出近七天最高值与 0，中、大号另标中间刻度；来源缺失的日期留空，不冒充 0；今天缺数据时只显示一次提示。
- 「桌面组件内容」可选跟随菜单栏、仅 Codex、仅 Claude 或同时显示两者。原生小号突出最紧张的一档，中号同时展示每个服务的五小时与七天进度，大号增加倒计时、完整重置日期和同步状态。百分比表示剩余额度；缺失的周期及重置时间明确标注，不推测数值。悬浮组件也支持 344 × 344 大号，按实际周期动态排版，服务无数据时给出连接或同步提示，记住尺寸和位置，并保留桌面实底／非桌面透明的行为。小、中号继续使用紧凑布局。
- 两类组件均按实际额度动态排版：仅一档时铺满可用宽度，手动填写的额度仍可显示，未连接服务显示连接／同步指引而不是假 0%。缺失周期不代表特定会员级别或无限额度。
- 默认每天检查一次更新，可关闭、手动检查，也支持经校验后自动安装。发布产物附带 `update.json`，记录版本、内部构建号、文件名及 SHA256，可识别同为 1.0.1 的较新构建。尚不支持该机制的旧安装需要先手动升级一次。替换失败会尝试恢复并重启旧版，成功后旧版备份移至废纸篓。
- 支持英语、简体中文、日语和西班牙语。
- 支持 macOS 12 及以上系统的 Apple Silicon 与 Intel Mac。
- 不发送遥测数据。

## 数据与兼容性

AgentReadout 会短暂启动 Codex 随附的 `codex app-server --stdio`，调用只读方法 `account/rateLimits/read`。解析器优先选择准确的 Codex 额度桶，兼容主要/次要周期及旧版数据结构。

这是本机集成接口，不是公开稳定 API。未来 Codex 更新后可能需要适配；自动同步不可用时仍可手动填写。额度获取不读取聊天记录；每日 Token 仅使用 Codex 官方日汇总和可用时的 Claude Code 现成统计缓存，不扫描会话日志，也不另建用量历史。程序不读取浏览器 Cookie、账号密码，也不发起模型生成请求。本工具与 OpenAI 无隶属或背书关系。

可选的 Claude 支持会先读取 Claude 客户端的本地 `plan-usage-history.json`（五小时／七天用量百分比和采样时间）；样本超过 15 分钟且本机有 Claude OAuth 授权时，才向 Anthropic 查询。该用量接口并非公开稳定 API。客户端缓存没有重置时刻；超过 24 小时的样本会被拒绝。开启 Claude 后仅在内存中使用本机 OAuth 令牌，不读取客户端 Cookie 或聊天正文。详见[隐私说明](../PRIVACY.md)。

## 构建与安装

运行 `zsh ./test-menu-insights.sh` 可离屏检查两张服务卡、同步旧数据与空数据及浅深色外观。`test-regressions.sh` 包含趋势断点、通知去重和官方每日汇总测试。统计窗口与分服务卡片的交互组织参考 [QuotaLens](https://github.com/mangiapanejohn-dev/QuotaLens)，实现独立编写，未引入其令牌存储或模型探测请求。

    cd quota-overlay
    ./build.sh
    ./install.sh

安装位置为 `~/Applications/Gauge for Codex.app`，登录启动项名称为 `com.qingtanlabs.gaugeforcodex`。安装完成会打开应用；新安装不默认登录自启，已有用户的启动选择在升级时保留。

「设置 → 通用 → 额度样式」可切换进度条 / 环形，统一应用于下拉卡片、原生桌面组件和悬浮组件；菜单栏紧凑显示不受影响。默认进度条，选择持久保存；WidgetKit 的实际刷新时机由系统控制。

运行 `zsh ./test-native-widget.sh` 渲染两种样式的三种原生组件尺寸，包含浅色、深色、模拟着色、国际化和额度边界。运行 `zsh ./test-floating-widget.sh` 可验证悬浮组件生产数据模型和菜单入口，并离屏渲染 198 张布局预览，覆盖两种样式、三种尺寸、双周期、仅七天、未连接、失败保留缓存、手动数据和单服务模式。测试不读取账号、不修改偏好，也不打开桌面窗口；实际拖动和底色切换仍需桌面验收。

运行 `zsh ./test-regressions.sh` 可检查原生时间线、旧数据标记、周期识别、地区日期格式、发布清单及更新失败恢复。额度变化及手动操作会主动请求 WidgetKit 刷新，并提供未来的倒计时、过期及重置时间线；后台请求会合并，实际执行时间仍由 macOS 调度。

安装时只退出当前应用包内的小组件扩展，并在重启前重新注册本应用，避免系统继续运行旧构建的扩展；不会重置全局小组件数据库。

悬浮组件直接集成在菜单栏进程中；macOS 14 及以上的原生桌面组件使用独立 WidgetKit 扩展。仅有 Xcode Command Line Tools 时可构建菜单栏程序和悬浮组件；构建新版原生组件还需要完整 Xcode、macOS 14 及以上 SDK 和 XcodeGen。若本机保留旧版原生扩展，它仍只显示 Codex，直至安装包含新版扩展的构建。
